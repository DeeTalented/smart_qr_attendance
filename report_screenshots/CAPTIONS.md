# Chapter 4 Figures — Smart QR Attendance System

Screenshots captured on 3 November 2026 from the running application.

**How they were produced (for your methodology / honesty statement):**

- Pages were generated by the real application code against a *copy* of the
  development database (fictitious sample data, `@example.com` accounts only),
  so the live database was not changed.
- A realistic class was simulated through the application's own routes: a lecturer
  started a session, seven students signed in, one duplicate attempt, one invalid
  code, one expired code and one non-enrolled student were tried, then the
  session was closed. The HTTP status of each screen is listed below.
- Debug mode was off and the QR code points to a LAN address
  (`http://192.168.0.10:5000`), as in a classroom deployment.
- Images were captured with headless Google Chrome: desktop at 1366 px wide, phone
  screens at 390 px wide rendered at 2x for print quality.
- The test-result figures show the verbatim output of
  `python -m unittest discover -p "test_*.py" -v` (full log: `test_output.txt`).
- `CSC101_attendance_export.csv` is the actual CSV file exported from the register
  in Figure 4.23.
